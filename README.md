# 📱 ملف Devices TikTok

## 🎯 الوصف
هذا المشروع يحتوي على 300 زوج من device_id و install_id لـ TikTok

## 📁 الملفات المتاحة

### 1. ملف devices.txt
- **المحتوى:** 300 زوج من device_id:install_id
- **الحجم:** 12KB
- **الصيغة:** device_id:install_id

### 2. صفحة التحميل (index.html)
- **الميزات:**
  - تصميم جميل وحديث
  - واجهة عربية
  - زر تحميل مباشر
  - زر نسخ المحتوى
  - عرض المحتوى مباشرة

## 🚀 كيفية الوصول للملف

### الطريقة الأولى - من Cursor:
1. افتح مجلد `workspace`
2. ستجد الملف `devices.txt`
3. انسخ المحتوى أو احفظ الملف

### الطريقة الثانية - من Terminal:
```bash
# عرض المحتوى
cat /workspace/devices.txt

# نسخ الملف
cp /workspace/devices.txt ~/Desktop/
```

### الطريقة الثالثة - من المتصفح:
1. افتح `index.html` في المتصفح
2. اضغط على زر "تحميل الملف"
3. أو اضغط على زر "نسخ المحتوى"

## 📋 مثال من المحتوى
```
7531135130632914439:7531135417245517575
7531134731602593296:7531135533209110273
7531135196386477576:7531135409310566152
```

## 🔧 كيفية تشغيل السكريبت
```bash
cd Generate-Device-Tiktok
python3 gen.py
```

## 📞 الدعم
إذا واجهت أي مشكلة، يمكنك:
1. فتح الملف `index.html` مباشرة في المتصفح
2. نسخ محتوى `devices.txt` يدوياً
3. تشغيل السكريبت مرة أخرى لتوليد ملف جديد
